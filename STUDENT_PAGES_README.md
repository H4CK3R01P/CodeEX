# 🎓 CodeEX Student Dashboard: Comprehensive Pages Guide

This document provides a full, detailed breakdown of every single section and page available in the **CodeEX Student Dashboard**. It explains exactly what each page is for, what features it contains, and what value it provides to the student.

---

## 🏠 1. Dashboard (Home)
**What it is:** The central hub and landing page after login. It provides a personalized bird's-eye view of the student's learning journey.
**What it explains/provides:** It answers "Where was I?" and "What should I do next?"
**Key Features & UI Elements:**
*   **"Resume Learning" Card:** A prominent widget showing the last incomplete problem or course chapter. One click routes the user directly back into the IDE.
*   **Activity Timeline:** A visual feed of the user's recent actions (e.g., "Solved Two Sum - 2 hours ago").
*   **Quick Stats Overview:** Miniature displays of current streak, total coins, and overall rank.
*   **Recommended Next Steps:** AI-driven suggestions for problems or courses based on the user's weak points (e.g., "You struggled with Arrays yesterday, try these beginner Array problems").

---

## 📅 2. Daily (Daily Challenge)
**What it is:** A dedicated page for the "Problem of the Day" (POTD) feature.
**What it explains/provides:** It encourages consistency and daily engagement by offering high-reward, time-limited challenges.
**Key Features & UI Elements:**
*   **The Daily Problem Card:** Displays today's problem, difficulty, and a countdown timer until it expires.
*   **Reward Indicator:** Shows the bonus coins/points available for solving it within the 24-hour window (e.g., "+50 Coins").
*   **Streak Calendar:** A monthly calendar view highlighting days the user successfully completed the POTD to motivate streak-building.
*   **"Solve Now" Button:** Routes the user to the Practice IDE with the POTD automatically loaded.

---

## 🤝 3. Collaborate (Collaboration Room)
**What it is:** A multiplayer, real-time coding environment for pair programming and group learning.
**What it explains/provides:** It facilitates peer-to-peer learning, allowing students to tackle complex problems together or prepare for mock interviews.
**Key Features & UI Elements:**
*   **Room Browser:** A lobby showing active public rooms seeking members, filterable by topic or difficulty.
*   **"Create Room" Widget:** Generate a unique link to invite friends to a private session.
*   **Shared IDE Workspace:** A collaborative code editor where multiple cursors are visible (like Google Docs).
*   **Team Mode AI:** The CodeEX Brain in this mode acts as a facilitator, refusing to give answers to individuals and instead dropping hints to the group as a whole.

---

## 📚 4. Learn
**What it is:** The structured educational curriculum and course library.
**What it explains/provides:** It teaches core computer science concepts, data structures, algorithms, and domain-specific knowledge (like Web Dev frameworks) from scratch.
**Key Features & UI Elements:**
*   **Course Modules:** Structured pathways (e.g., "100 Days of Code", "Mastering Graphs").
*   **Interactive Markdown Reader:** Beautiful, rich-text lesson pages.
*   **Teacher Agent Integration:** Users can highlight confusing text within the lesson, triggering the AI Teacher to pop up and explain the concept with fresh, personalized analogies.
*   **Progress Tracking:** Progress bars for each chapter and module.

---

## 🗂️ 5. Problems (Library)
**What it is:** The master database of all coding challenges available on CodeEX.
**What it explains/provides:** It allows students to freely browse, filter, and select problems to practice specific skills outside of a structured course.
**Key Features & UI Elements:**
*   **Advanced Datatable:** A grid listing all problems.
*   **Filters & Tags:** Filter by Difficulty (Easy/Medium/Hard), Status (Solved/Attempted/Unsolved), Company Tags (Google, Meta, Amazon), and Topic (Dynamic Programming, Trees).
*   **Acceptance Rate Column:** Shows the global success rate for each problem.
*   **One-Click Routing:** Clicking any row instantly loads that problem in the Practice IDE.

---

## 💻 6. Practice (The IDE Workspace)
**What it is:** The core interactive sandbox where all coding happens.
**What it explains/provides:** The environment where students apply their knowledge, write code, run tests, and interact with the AI agents.
**Key Features & UI Elements:**
*   **3-Pane Split Layout:** Problem Description (Left), Monaco Code Editor (Center), AI Brain Sidebar (Right).
*   **Execution Sandbox:** "Run Code" against sample test cases and "Submit" against hidden test cases.
*   **The 9 AI Agents:** Direct access to Planner, Hint, Debugging, and Coding agents via the Action Grid to get unstuck safely.

---

## 🏆 7. Compete
**What it is:** The arena for timed, competitive programming contests.
**What it explains/provides:** Simulates high-pressure environments like coding interviews or global hackathons.
**Key Features & UI Elements:**
*   **Upcoming Contests:** Registration cards for future tournaments.
*   **Live Leaderboards:** Real-time ranking of participants based on solve speed and penalty time.
*   **Strict Arena Mode:** When a user enters a contest, they are placed in a locked-down version of the Practice IDE where **ALL AI ASSISTANCE IS DISABLED** (except for basic planning/scratchpad features).

---

## 📝 8. Tests
**What it is:** A portal for formal assessments and certification exams.
**What it explains/provides:** Used by educators or the platform to formally evaluate a student's proficiency without gamification.
**Key Features & UI Elements:**
*   **Proctored Environment:** Full-screen mode requirements and tab-switching warnings.
*   **Exam Timer:** A strict countdown clock.
*   **Zero AI Assistance:** The CodeEX Brain is completely disabled here.
*   **Results Dashboard:** Post-exam breakdown of performance by topic.

---

## 🎖️ 9. Achieve
**What it is:** The gamification and milestone tracking center.
**What it explains/provides:** It taps into psychological reward systems, giving students tangible goals to strive for beyond just solving problems.
**Key Features & UI Elements:**
*   **Badge Gallery:** A display of earned and locked badges (e.g., "10 Day Streak", "Graph Master", "Bug Squasher").
*   **Unlock Criteria:** Clicking a locked badge reveals exactly what the student must do to earn it.
*   **Certificates:** Downloadable PDF certificates for completing entire "Learn" modules.

---

## 🌐 10. Social
**What it is:** The community and networking hub.
**What it explains/provides:** Connects students with peers, fostering a sense of community and healthy competition.
**Key Features & UI Elements:**
*   **Global Activity Feed:** A scrolling feed of platform activity ("Alex just earned the Tree Master badge!").
*   **Friends List:** See who is currently online and what problem they are tackling.
*   **Public Profiles:** Click a user to see their stats, badges, and recent public submissions.

---

## 📊 11. Analytics
**What it is:** A deep dive into the user's personal data and performance metrics.
**What it explains/provides:** Helps the student identify their strengths and weaknesses so they can optimize their study time.
**Key Features & UI Elements:**
*   **Submission Heatmap:** A GitHub-style contribution graph showing daily activity over the year.
*   **Skill Radar Chart:** A spider-web chart mapping proficiency across different topics (Math, Strings, Arrays, etc.).
*   **Accuracy Metrics:** Ratios of Accepted (AC) vs Wrong Answer (WA) submissions to track coding precision.

---

## 🪙 12. Coins (The Store)
**What it is:** The virtual economy marketplace of CodeEX.
**What it explains/provides:** Gives value to the points earned by solving problems and maintaining streaks, keeping engagement high.
**Key Features & UI Elements:**
*   **Coin Balance:** Prominent display of current wealth.
*   **Storefront:** Items available for purchase using virtual coins.
*   **Cosmetics:** Buy dark mode themes, neon code editor syntax highlights, or special borders for your social avatar.
*   **Power-ups:** Buy "Extra Hints" or "Streak Freezes" (to save a daily streak if you miss a day).
