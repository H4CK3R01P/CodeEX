## 🚀 Quick Start

### For Users

1. **Access the Platform**
   ```
   Open your browser and navigate to CodeEX
   ```

2. **Complete Onboarding**
   - Enter your name and contact
   - Verify OTP
   - Select your profile type
   - Choose your domain

3. **Start Learning!**
   - Try the daily challenge
   - Solve your first problem
   - Connect with friends
   - Track your progress

### For Developers

1. **Clone the Repository**
   ```bash
   git clone https://github.com/your-org/codeex.git
   cd codeex
   ```

2. **Install Dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Set Up Environment**
   ```bash
   cp .env.example .env
   # Configure your Supabase credentials
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

5. **Open Browser**
   ```
   Navigate to http://localhost:5173
   ```
