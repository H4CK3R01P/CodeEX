## 🔥 Daily Challenge

**How to Access:** Dashboard → Daily

### What You Can Do:
1. **Daily Problem**
   - New challenge every day
   - 24-hour window
   - Auto-resets at midnight
   - Earn rewards

2. **Streak System**
   - Track consecutive days
   - 30-day visual calendar
   - Current & longest streak
   - Don't break the chain!

3. **Rewards**
   - +10 coins per completion
   - +5 XP per day
   - Milestone bonuses:
     - 7 days: +50 coins
     - 30 days: +200 coins + badge
     - 100 days: +1000 coins + legendary badge

4. **Progress Tracking**
   - Visual calendar
   - Completion checkmarks
   - Streak stats
   - Countdown timer

### Quick Tips:
- ⏰ Complete before midnight
- 🔥 Never miss a day
- 🎯 Build the habit
- 💎 Earn milestone rewards
