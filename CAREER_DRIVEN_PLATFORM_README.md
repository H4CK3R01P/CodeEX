# 🚀 CodeEX: The Ultimate Domain-Driven Global Platform

This document outlines the core architecture of CodeEX. CodeEX is **not just a coding platform**; it is the ultimate global preparation and career-building engine. 

Immediately after logging in and selecting the **"Student"** profile, a user must select their specific Career or Examination Domain. Once selected, the entire platform—from the UI to the AI Brain, to the problem sets and leaderboards—completely transforms to serve that exact pathway.

---

## 🌍 1. The Global Domain Selection

CodeEX currently supports two massive categories of domains: **Software Development & Coding** and **Competitive Examinations**.

### 💻 Software Development & Coding Domains
1.  **Competitive Programming:** Focuses purely on DSA, Algorithms, and Problem Solving (ACM ICPC style).
2.  **Frontend Development:** Focuses on React, CSS, JavaScript, and building user interfaces.
3.  **Backend Development:** Focuses on APIs, Databases, and System Design architecture.
4.  **Mobile Development:** Focuses on iOS, Android, and React Native application building.
*(Note: Full Stack & Data Analyst can be derived from these paths or added natively).*

### 📚 Competitive Examination Domains (Global Top Exams)
1.  **JEE (Main & Advanced):** India's premier Engineering Entrance Exam (Physics, Chemistry, Math).
2.  **NEET:** India's premier Medical Entrance Exam (Physics, Chemistry, Biology).
3.  **Gaokao:** China's National College Entrance Examination (The toughest standardized test globally).
4.  **UPSC:** India's top-tier Civil Services Examination (IAS, IPS).
5.  **MPSC:** Maharashtra Public Service Commission.
6.  **GATE:** Graduate Aptitude Test in Engineering.
7.  **CAT:** Common Admission Test for top global MBA and business school admissions.

## 🔄 2. Complete Platform Morphing (How it Personalizes)

When a user selects their domain (e.g., *NEET* vs *Frontend Development*), **everything changes**. The platform uses the Domain Personalization Engine to rewrite the experience:

### A. The "Practice" Environment Morphs
*   **For Tech Domains (Frontend, Backend, CP):** The Practice area is a **Code Editor IDE** (Monaco) with a terminal output, compiler, and syntax highlighting.
*   **For Exam Domains (Gaokao, JEE, UPSC, CAT):** The Practice area morphs into an **Interactive Assessment UI** (MCQs, integer-type questions, assertion-reasoning). The compiler is replaced by an interactive rough-pad/whiteboard for calculations.

### B. The "Problems" Library Morphs
*   **Frontend:** The library lists tasks like "Build a React Carousel".
*   **Backend:** The library lists tasks like "Design a Rate Limiter".
*   **Gaokao / JEE / NEET:** The library lists thousands of Previous Year Questions (PYQs), categorized by chapters like "Thermodynamics" or "Genetics".

### C. The "Learn" Section Morphs
*   **Tech Domains:** Shows interactive markdown courses on frameworks and system architectures.
*   **Exam Domains:** Shows highly structured syllabus chapters, interactive diagrams (e.g., Human Anatomy for NEET), and formula cheat sheets.

### D. The "Compete" Section Morphs
*   **Coding Domains:** Users enter timed "Hackathons" or algorithmic coding contests.
*   **Exam Domains:** Users enter "All-India Mock Tests" or "Global Mock Exams" on Sundays, competing on leaderboards based on accuracy and negative marking rules.

### E. The AI Brain Adopts a New Persona
The CodeEX AI 9-Agent System dynamically swaps its entire knowledge base.
*   **Teacher Agent (Frontend):** Explains how the Virtual DOM works.
*   **Teacher Agent (JEE):** Explains the concepts of Rotational Mechanics using 3D analogies.
*   **Hint Agent (Backend):** Hints at using an "In-Memory Cache". 
*   **Hint Agent (NEET):** Hints at "Remembering the Kreb's Cycle".

## 🎯 3. The 3 Pillars of Readiness

Regardless of whether the user is a Software Engineer candidate or a UPSC aspirant, the platform drives them using three core pillars:

### 🗺️ Pillar 1: The Roadmap (Syllabus Tracker)
*   **Tech:** A skill tree unlocking technologies (HTML -> JS -> React).
*   **Exams:** A syllabus completion tracker (e.g., tracking 11th and 12th-grade Physics/Chemistry chapters). 
*   Provides a global "Readiness Score" comparing their completion rate to historical top rankers.

### 🏗️ Pillar 2: The Portfolio / Past Papers
*   **Tech:** A cloud IDE to build and deploy real-world apps to show employers.
*   **Exams:** A personalized archive of their performance in Past Year Papers, highlighting exact weak topics (e.g., "You are weak in Organic Chemistry").

### 🎤 Pillar 3: AI Mock Interviews & Vivas
*   **Tech:** AI conducts a technical FAANG interview, asking system design questions and grading communication.
*   **UPSC / MPSC:** AI conducts a grueling mock "Personality Test / Interview" via chat/voice to simulate the actual administrative boards.
*   **JEE / NEET / Gaokao:** AI conducts rapid-fire oral viva sessions to test formula memory and concept retention under extreme pressure.
